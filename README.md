This study investigates the early prediction of diabetes using the Pima Indians Diabetes 
Database, a publicly available dataset from Kaggle containing 768 patient records and 9 
clinical features. Predicting diabetes is crucial because early detection allows for timely 
medical intervention and prevents serious complications. We evaluated three machine 
learning models: Logistic Regression, Decision Tree, and K-Nearest Neighbors. Our results 
show that Logistic Regression is the most effective model, achieving an accuracy of 0.75 and 
an F1-score of 0.66 for the positive class. An interesting finding is that while Logistic 
Regression and Decision Tree shared similar accuracy levels (0.75 vs 0.75), Logistic 
Regression proved more stable with a Cross-Validation mean of 0.77 compared to 0.72 for 
the Decision Tree. These findings support using stable linear models for medical diagnostic 
tools.
